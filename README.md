**Инструкция по запуску программы** 

**Присутствующие роли:**

Гость:
- просмотр услуг без авторизации.

Клиент:

- авторизация;
- просмотр услуг карточками с фото, описанием, ценой и скидкой.

Администратор:

- просмотр услуг карточками;
- поиск по названию, описанию и типу через LineEdit;
- фильтрация по типу услуги через ComboBox;
- сортировка по цене (по возрастанию / убыванию) через ComboBox;
- добавление новой услуги через диалог;
- удаление услуги кнопкой прямо в карточке.

**Логины и пароли**

- admin/123	
- client/123	

Как запустить
1. В MySQL Workbench выполнить файл:
- db.txt
2. Установить зависимости:
- pip install -r requirements.txt
- pip install PyQt6 pymysql
3. Запустить в терминале или с помощью кнопки Run 'main'':
- python main.py

**Подключение к БД**

В файле service/database.py подключение прописано прямо в классе DBService.__init__:

host='localhost'
user='root'
password='...'
database='photo_ate'

**UI**

Все окна лежат в папке view/. .ui-файлы открываются в Qt Designer — можно изменить objectName и сразу использовать в Python. 
В коде подключаются через скомпилированные _ui.py файлы (через pyuic6).

**База данных**
База называется photo_ate. Таблицы:

- role — роли пользователей (Администратор, Клиент, Гость);
- user — пользователи с привязкой к роли;
- type_serv — типы услуг;
- service — услуги с ценой, скидкой, описанием и фото.
